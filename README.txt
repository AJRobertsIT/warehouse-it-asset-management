# Enterprise IT Asset Management System

## Overview

This project simulates an enterprise IT asset management system for a warehouse and distribution environment. It was designed to demonstrate how IT departments organize, document, and track technology assets used throughout warehouse operations.

The project includes a detailed asset inventory and an executive dashboard for reporting asset status and inventory metrics.

---

## Objectives

- Create a centralized inventory of IT assets
- Track workstations, servers, scanners, printers, and networking equipment
- Organize assets using professional naming conventions
- Build a management dashboard for reporting
- Demonstrate documentation and IT asset management skills
